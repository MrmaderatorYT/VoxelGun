# Векторні значки стрічки вбивств

Кожен файл `ic_kill_*.svg` має відповідний Android-ресурс із тією самою назвою
в `app/src/main/res/drawable/ic_kill_*.xml`. У 12 парах використано **ідентичні
контури** (`d` у SVG та `android:pathData` у VectorDrawable), однакову білу
заливку, товщину й заокруглення штрихів. Розмір полотна — 24 × 24; контурні
значки мають штрих 1,8–1,9 одиниці. Компактна стрічка використовує значки
обставин 11 dp та значок джерела шкоди 13 dp.

## Легенда

| Назва ресурсу | Значення |
| --- | --- |
| `ic_kill_headshot` | Смертельне влучання в голову. Не позначає попередній несмертельний headshot. |
| `ic_kill_scoped` | Постріл із прицілюванням зі снайперської зброї з оптичним прицілом: AWM-X, Scout-V, Dragunov-S, Barrett-M. |
| `ic_kill_noscope` | Постріл без прицілювання з тієї самої снайперської зброї. Звичайним гвинтівкам і пістолетам no-scope не нараховується. |
| `ic_kill_airborne` | Стрілець був у повітрі в момент пострілу або кидка; не стан жертви й не стан власника під час пізнішого вибуху. |
| `ic_kill_knife` | Фактичне джерело смертельної шкоди — ніж або інша зброя ближнього бою, включно зі швидким ударом без перемикання слота. |
| `ic_kill_blinded` | Стрілець був помітно засліплений флешкою в момент пострілу або кидка. Значок — перекреслене око. |
| `ic_kill_flash_victim` | Жертва була помітно засліплена флешкою в момент смертельного влучання. Значок — око з променями спалаху. |
| `ic_kill_wallbang` | Смертельне влучання через фактичне пробиття тонкої стіни; не просто великий показник пробиття у характеристиках зброї. |
| `ic_kill_grenade` | Фактичне джерело шкоди — граната. Автоматичний вибух модифікатора Explosive Death також використовує цю категорію, але не успадковує стан прицілювання/польоту загиблого. |
| `ic_kill_rocket` | Фактичне джерело шкоди — ракета з гранатомета. |
| `ic_kill_fall` | Загибель від падіння або іншої шкоди середовища без зброї; не показується як удар ножем. |
| `ic_kill_rifle` | Узагальнений значок решти вогнепальної зброї. Точна назва пістолета, гвинтівки, дробовика тощо залишається в тексті запису. |

Позначки можуть поєднуватися: наприклад, headshot + no-scope + airborne.
Майже прозорий залишок спалаху не рахується засліпленням; поточний поріг
визначений у `KillContext.FLASH_THRESHOLD`. Для відкладених влучань ракетою
чи гранатою стан стрільця зберігається під час запуску, а засліплення жертви
перевіряється під час влучання. Пізніші приземлення, зміна зброї або одужання
стрільця не змінюють уже зафіксовані позначки.

Стрічка повернута до старого компактного вигляду: без фонових карток,
із природною шириною запису, вирівнюванням праворуч і кроком рядків 28 dp.
Ніки мають розмір 12 dp, назва зброї — 10 dp. Стрічка показує до п’яти
останніх записів. Її доступна висота враховує
поточне розташування патронів, інших показників і сенсорних кнопок,
зокрема після редагування HUD. Показуються лише найновіші записи, що вміщуються,
без перекриття прицілу, патронів або керування.

## Використання та редагування

Під час гри використовуються Android **VectorDrawable**-ресурси. SVG — це
редаговані вихідні файли, а не runtime-формат: SVG-парсер і растрові файли
для стрічки не потрібні. Колір та прозорість можна змінювати на рівні
Drawable без перемальовування контурів.

При редагуванні значка потрібно синхронно оновити контури й стилі в обох
файлах пари та перевірити читабельність у малому розмірі. Не додавайте
растрові вставки, шрифтові гліфи чи SVG-ефекти, які не підтримуються
VectorDrawable.
