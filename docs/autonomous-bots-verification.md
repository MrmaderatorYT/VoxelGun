# Перевірка самостійної тактики ботів

Станом на 2 жовтня 2026 року боти обирають локальну співпрацю самостійно, без наказів гравця. Цей звіт описує зміни, підтверджує успішну збірку та локальні й емуляторні перевірки, але не підтверджує встановлення цієї версії на фізичний планшет чи його продуктивність.

## Що змінилося

- Прибрано ручні накази Attack / Defend / Follow, типові F6–F8, пункт паузи, підказки та API наказів. Старі збережені `SQUAD_*` прив’язки ігноруються; решта прив’язок завантажується за назвою дії.
- Бот сам обирає підтримку корисного союзника, самостійний наступ, обхід або прикриття свого сектора. Гравець не має пріоритету над іншими союзниками.
- Підтримка враховує здоров’я, стиль, напрямок руху, спільну публічну ціль, відстань і видимість. Нерухомий союзник не притягує бота до респауну.
- Не більше двох помічників на союзника; окремі позиції позаду з боків; без ланцюжків слідування. Позиції підтримки не міняються місцями через ротацію бюджету видимості.
- Загибель, зупинка, відступ, критичне поранення чи велика відстань скасовують підтримку. Видимість через змінений рельєф повторно перевіряється на наступному циклі планування.
- Обидві команди користуються однаковими правилами. Стратегічний розподіл цілей, перегрупування, безпечне передове відродження та bhop збережені.
- Повтор траси (`T` за замовчуванням, з можливістю переназначення) залишено лише для Movement Training. Це не команда ботам.

- `:app:testDebugUnitTest`: **362 тести**, 69 наборів, 0 помилок / невдач / пропусків. Серед них 18 сценаріїв `SquadCoordinatorTest`, нова перевірка зміни цілі під час затримки повторного пошуку маршруту та перевірки вартості симуляції.
- `:app:assembleDebug`, `:app:assembleDebugAndroidTest`, `:app:lintDebug`: успішно. Lint: **0 errors, 83 warnings**; попередження не приховано і не прирівняно до чистої перевірки.
- Емулятор `emulator-5556`: **10 Android-тестів, 0 невдач, 73.833 с**, без ручного Home чи примусового завершення. Перевірено нативну видимість та позиції підтримки, передове відродження, bhop на трьох приземленнях, соло-режими, реальні натискання паузи / повтору траси та сумісність прив’язок.
- Перший Android-прогін завершився лише після ручного Home через очікування загального простою UI під час закриття тестової Activity.
